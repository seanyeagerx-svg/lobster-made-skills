# 跨窗口对账

1. **界定相关会话**：仅在本次用户授权的可见范围内，用当前会话工具筛选与该共享资源有关的窗口，按即将修改的共享资源筛选；自动任务或其他 agent 只有在确实共享该资源时纳入。完成标准：清单含当前窗口、相关窗口及工具可见范围，未把受限列表当成全量。
2. **读最近动态**：用 `sessions_history` 从每个相关窗口最近 5–10 条开始，发现未完结决定或截断时向前追查；读取今天的工作记录与共享状态锚点。完成标准：每个窗口有带时间、来源的当前决定/待办摘要；无法读取的窗口标记未知。
3. **重置前保全**：涉及重置/清空时先核对该会话可获得的完整历史，把重要原话、产物和未完任务保存到授权位置，读回确认；历史缺失时报告缺口并暂停依赖该缺口的清理，不自行读取其他用户、原始数据库或块设备。完成标准：重要内容已保存且可读回，或明确报告历史缺口并暂缓依赖该缺口的清理。
4. **检查冲突**：对照即将进行的动作，核对重复工作、矛盾决定与资源竞争；有冲突时向当前用户说明具体证据并解决依赖。完成标准：无已知冲突，或冲突已有明确处理决定；未知状态未被当成无冲突。
5. **落下对账结论**：向用户交付相关窗口状态、计划动作和冲突结论；只有另有记录授权时才保存，保留时间与来源，只在相关任务中使用读到的信息。完成标准：结论可追溯，动作与最新已确认决定一致后再执行。
