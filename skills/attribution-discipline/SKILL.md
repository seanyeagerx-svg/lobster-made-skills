# 归因纪律

核对仅服务于本次要求的输出；加载本技能不新增记忆写入、外发或跨会话读取的权限。

1. **提取行为陈述**：检查拟输出或拟写入记忆的每个行为动词、被动句、提案和规则引用，给每条陈述编号。完成标准：所有涉及「谁做了什么」的句子均在核对清单中。
2. **填写角色与证据**：逐项回答「谁授权/拍板？谁实际执行？谁提供材料/信息？」并为每个答案附原始消息、工具结果或文件位置。角色由证据决定，用户、AI、第三方都可能执行，同一人也可承担多个角色；无对应角色写「不适用」，缺证写「待确认」。疑难混合行为查 [样例与检查表](references/examples-and-checklist.md)。跨会话流转的信息（sessions_send/heartbeat 转来的更正、发现、裁决）转述给用户时，原主体（谁发现/谁更正/谁执行）随信息一起转——漏转会把自查写成用户归属性更正（例如，把自动任务的自查误写成用户更正）。完成标准：每项三栏均已填写，已知归属均有可定位证据，转述句的主体与原会话一致。
3. **核对证据状态**：对检索摘要回查原文；对现行状态核对来源的时间与可见范围；对规则核对批准者、适用范围和是否仍生效。提案未经确认时标「未确认提案」。必要时用 [证据选择步骤](references/case-evidence.md) 处理快照冲突。完成标准：事实、未决提案和过时状态已分开，未知归属显式标注。
4. **重写压缩句**：按实际行为拆开授权、执行和来源，补齐会造成误解的隐式主语，保留来源。完成标准：输出各动词的主语与步骤 2 的执行者一致，授权和提供材料未被改写成执行。
5. **出口逐项对照**：将最终稿与编号清单逐条比对：授权者是否仍可见、执行者是否正确、提供者是否保留、证据是否支持该动词、待确认项是否仍标注。发现错位后复查同段全部条目。完成标准：每项五问均通过或明确不适用；无证据项均以待确认措辞输出，才可发送或写入记忆。
